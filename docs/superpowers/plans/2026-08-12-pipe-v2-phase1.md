# Pipe v2 — Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Pipe's proven v1 transport into an easy-to-adopt library: a coroutine/Flow-first public API, suspendable authorization, provider discovery, multi-pane providers, an opt-in typed-message module, and a published, binary-compatibility-tracked artifact.

**Architecture:** Keep the v1 security core and SCVH transport intact but wrap them in a new public surface. `PipeView.open()` becomes a `suspend` function that throws a sealed `PipeException` and returns a `PipeSession` exposing `StateFlow<PipeState>` + `Flow<PipeMessage>`. The provider base class becomes multi-pane and suspend-authorized. The raw AIDL is hidden behind `@RestrictTo`. Typed messaging lives in a sibling `:pipe-serialization` module. A `CoroutineDispatcher` is injected so gate/session logic is unit-testable off-device.

**Tech Stack:** Kotlin 2.2.x, AGP 8.13.x, compileSdk 36, minSdk 35, AIDL, kotlin-parcelize, kotlinx-coroutines-android, kotlinx-serialization (CBOR) in `:pipe-serialization` only, JUnit4 + kotlinx-coroutines-test (JVM), AndroidX test + UiAutomator (instrumented), maven-publish + binary-compatibility-validator.

## Global Constraints

- `minSdk = 35`, `compileSdk = 36`, `targetSdk = 36` everywhere.
- Namespace `tech.ssemaj.pipe`; Maven group `tech.ssemaj.pipe`; artifacts `pipe` and `pipe-serialization`.
- This is a **clean v2 breaking change** — nothing consumes v1, so freely replace public API. The **security invariants are unchanged**: provider identity is `Binder.getCallingUid()` only; host identity is the resolved+bound `ComponentName` only; callback binders stay uid-gated (v1 commit 75d6206); empty/unreadable cert sets deny.
- `:pipe` depends on `kotlinx-coroutines-android` but **NOT** on `kotlinx-serialization` (that stays in `:pipe-serialization`).
- All host-facing flows/callbacks emit on the injected dispatcher, default `Dispatchers.Main.immediate`.
- The AIDL interfaces, `OpenSpec`, and `Protocol` are `@RestrictTo(RestrictTo.Scope.LIBRARY_GROUP)` — no third party may implement the transport.
- Provider intent action exact string: `tech.ssemaj.pipe.action.OPEN_PANE`, published as `Pipe.ACTION_OPEN_PANE`.
- Kotlin only. TDD: every behavior lands with a failing test first. Conventional commits. Commit after every task.
- Public API is tracked by binary-compatibility-validator; any task changing the surface runs `./gradlew apiDump` and commits the updated `pipe/api/pipe.api` (and `pipe-serialization/api/...`).
- Exact string keys reserved by the library in the `PipeMessage` Bundle: `"tech.ssemaj.pipe.codec.cbor"` (typed payload bytes), `"tech.ssemaj.pipe.codec.type"` (payload type id). App keys must not collide; documented.

`Authorizers.kt` — same logic as v1, classes now implement the suspend interface (the bodies need no `suspend` keyword since they don't suspend, but override a suspend function):
```kotlin
package tech.ssemaj.pipe.auth

import tech.ssemaj.pipe.core.PipeRequest

class SameSigningKeyAuthorizer(localCertsSha256: Set<String>) : PipeAuthorizer {
    private val local = localCertsSha256.map { it.lowercase() }.toSet()
    override suspend fun authorize(peer: PeerIdentity, request: PipeRequest): AuthDecision {
        if (peer.signingCertSha256.isEmpty()) return AuthDecision.Deny("peer has no readable signing certs")
        return if (peer.signingCertSha256.any { it.lowercase() in local }) AuthDecision.Allow
        else AuthDecision.Deny("peer signing certs do not match local signing key")
    }
}

class AllowlistAuthorizer(certSha256: Set<String>) : PipeAuthorizer {
    private val allowed = certSha256.map { it.lowercase() }.toSet()
    override suspend fun authorize(peer: PeerIdentity, request: PipeRequest): AuthDecision {
        if (peer.signingCertSha256.isEmpty()) return AuthDecision.Deny("peer has no readable signing certs")
        return if (peer.signingCertSha256.any { it.lowercase() in allowed }) AuthDecision.Allow
        else AuthDecision.Deny("peer signing certs not in allowlist")
    }
}

fun anyOf(vararg authorizers: PipeAuthorizer): PipeAuthorizer = PipeAuthorizer { peer, request ->
    val reasons = mutableListOf<String>()
    for (a in authorizers) when (val d = a.authorize(peer, request)) {
        is AuthDecision.Allow -> return@PipeAuthorizer AuthDecision.Allow
        is AuthDecision.Deny -> reasons += d.reason
    }
    AuthDecision.Deny(if (reasons.isEmpty()) "no authorizers configured" else reasons.joinToString("; "))
}
```

```kotlin
import tech.ssemaj.pipe.auth.AuthDecision
import tech.ssemaj.pipe.auth.IdentityResolver
import tech.ssemaj.pipe.auth.PipeAuthorizer
import tech.ssemaj.pipe.core.PipeRequest
```

```kotlin
class HostGate(
    private val resolver: IdentityResolver,
    private val authorizer: PipeAuthorizer,
) {
    suspend fun admit(component: ProviderComponent, request: PipeRequest): GateResult {

    }
```

```kotlin
package tech.ssemaj.pipe.serialization

import android.os.Bundle
import kotlinx.serialization.cbor.Cbor
import kotlinx.serialization.serializer
import tech.ssemaj.pipe.core.PipeMessage

object PipeCodec {
    private const val KEY_BYTES = "tech.ssemaj.pipe.codec.cbor"
    private const val KEY_TYPE = "tech.ssemaj.pipe.codec.type"

    inline fun <reified T> encode(payload: T): PipeMessage {
        val bytes = Cbor.encodeToByteArray(serializer<T>(), payload)
        val b = Bundle().apply { putByteArray(KEY_BYTES, bytes); putString(KEY_TYPE, T::class.qualifiedName) }
        return PipeMessage(payload = b)
    }
    inline fun <reified T> decodeOrNull(message: PipeMessage): T? {
        if (message.payload.getString(KEY_TYPE) != T::class.qualifiedName) return null
        val bytes = message.payload.getByteArray(KEY_BYTES) ?: return null
        return runCatching { Cbor.decodeFromByteArray(serializer<T>(), bytes) }.getOrNull()
    }
    // expose the key constants for the inline funcs
    const val PUBLIC_KEY_BYTES = KEY_BYTES
    const val PUBLIC_KEY_TYPE = KEY_TYPE
}
```
